MiniMax-Hailuo-02 模型 首尾帧视频生成功能
新增“last_frame_image”参数，配合“first_frame_image”参数，来控制视频生成的起始与结束画面
支持分辨率及时长：768P (6s，10s) 和 1080P (6s)
请求参数
Header 参数
Authorization
string
可选
默认值:
Bearer {{YOUR_API_KEY}}
Body 参数
application/json
model
string
必需
可用值：MiniMax-Hailuo-02
prompt
string
必需
duration
integer
可选
first_frame_image
string
必需
将指定图片作为视频的起始帧。支持公网 URL 或 Base64 编码的 Data URL (data:image/jpeg;base64,...)。
last_frame_image
string
必需
将指定图片作为视频的结束帧。支持公网 URL 或 Base64 编码的 Data URL (data:image/jpeg;base64,...)。
resolution
enum<string>
可选
枚举值:
768P
1080P
prompt_optimizer
boolean
可选
是否自动优化 prompt，默认为 true。设为 false 可进行更精确的控制

{
"model": "string",
"prompt": "string",
"duration": 0,
"first_frame_image": "string",
"last_frame_image": "string",
"resolution": "768P",
"prompt_optimizer ": true
}
请求示例代码
http.client
Requests
import http.client
import json

conn = http.client.HTTPSConnection("")
payload = json.dumps({
"model": "string",
"prompt": "string",
"duration": 0,
"first_frame_image": "string",
"last_frame_image": "string",
"resolution": "768P",
"prompt_optimizer ": True
})
headers = {
'Authorization': 'Bearer {{YOUR_API_KEY}}',
'Content-Type': 'application/json'
}
conn.request("POST", "/minimax/v1/video_generation", payload, headers)
res = conn.getresponse()
data = res.read()
print(data.decode("utf-8"))
