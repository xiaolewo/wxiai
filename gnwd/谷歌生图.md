# OpenAI Dall-e 格式
## Nano-banana 图生图 API

接口地址  
POST /v1/images/edits  

最后修改时间 2 天前  

支持多图参考  

---

## 请求参数  

### Header  
参数 Authorization  
类型 string  
必需 否  
示例值 Bearer {{YOUR_API_KEY}}  
说明 API Key 鉴权  

---

### Body multipart/form-data  

参数 model  
类型 string  
必需 是  
示例值 nano-banana  

参数 prompt  
类型 string  
必需 是  
示例值 一只猫  

参数 image  
类型 file  
必需 是  
说明 支持多图或不带参考图  
示例值 ["file://E:\Downloads\1745936044575403500.png", "file://E:\Downloads\微信图片_20250826114255_1785.jpg"]  

参数 response_format  
类型 string  
必需 否  
说明 返回结果格式  
可选值 url b64_json  
示例值 url  

---

## 请求示例  

Python http.client  

```python
import http.client
import mimetypes
from codecs import encode

conn = http.client.HTTPSConnection("{{BASE_URL}}")
dataList = []
boundary = 'wL36Yn8afVp8Ag7AmP8qZ0SA4n1v9T'

# model
dataList.append(encode('--' + boundary))
dataList.append(encode('Content-Disposition: form-data; name=model;'))
dataList.append(encode('Content-Type: text/plain'))
dataList.append(encode(''))
dataList.append(encode("nano-banana"))

# prompt
dataList.append(encode('--' + boundary))
dataList.append(encode('Content-Disposition: form-data; name=prompt;'))
dataList.append(encode('Content-Type: text/plain'))
dataList.append(encode(''))
dataList.append(encode("一只猫"))

# image 1
dataList.append(encode('--' + boundary))
dataList.append(encode('Content-Disposition: form-data; name=image; filename={0}'.format('E:\\Downloads\\1745936044575403500.png')))
fileType = mimetypes.guess_type('E:\\Downloads\\1745936044575403500.png')[0] or 'application/octet-stream'
dataList.append(encode('Content-Type: {}'.format(fileType)))
dataList.append(encode(''))
with open('E:\\Downloads\\1745936044575403500.png', 'rb') as f:
    dataList.append(f.read())

# image 2
dataList.append(encode('--' + boundary))
dataList.append(encode('Content-Disposition: form-data; name=image; filename={0}'.format('E:\\Downloads\\微信图片_20250826114255_1785.jpg')))
fileType = mimetypes.guess_type('E:\\Downloads\\微信图片_20250826114255_1785.jpg')[0] or 'application/octet-stream'
dataList.append(encode('Content-Type: {}'.format(fileType)))
dataList.append(encode(''))
with open('E:\\Downloads\\微信图片_20250826114255_1785.jpg', 'rb') as f:
    dataList.append(f.read())

# response_format
dataList.append(encode('--' + boundary))
dataList.append(encode('Content-Disposition: form-data; name=response_format;'))
dataList.append(encode('Content-Type: text/plain'))
dataList.append(encode(''))
dataList.append(encode("url"))

dataList.append(encode('--' + boundary + '--'))
dataList.append(encode(''))

body = b'\r\n'.join(dataList)
headers = {
   "Authorization": "Bearer {{YOUR_API_KEY}}",
   "Content-type": "multipart/form-data; boundary={}".format(boundary)
}

conn.request("POST", "/v1/images/edits", body, headers)
res = conn.getresponse()
data = res.read()
print(data.decode("utf-8"))
```

---

## 返回响应  

成功响应 200 OK  

```json
{}
```

说明  
返回结果为 JSON 对象 具体内容取决于 response_format 参数  
当 response_format=url 时 返回图片链接  
当 response_format=b64_json 时 返回 Base64 编码的图像数据
